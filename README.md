

Temporary Euphoria

**Live page: [AR Experience](https://benfitz1110-dev.github.io/myproject-oak-tree/)**

Our object contrasts earned happiness with manufactured happiness, challenging the viewer to choose between them. The laptop represents a quieter but lasting contentment that comes from doing meaningful work, while the cigarette represents an intense but fleeting high that comes from chasing pleasure. The cigarette animation is already dried up when it is viewed in AR whereas the laptop features an infinite loop and is always in an animated state
